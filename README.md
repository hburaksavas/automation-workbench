# Automation Workbench

Otomasyon projeleri ve araçları için ortak depo. Her proje `projects/` altında kendi derleme ve çalıştırma talimatlarını barındırır.

| Proje | Açıklama |
|---|---|
| [TestTR](projects/testtr/README.md) | Türkçe UI senaryolarını Java ve JUnit testlerine dönüştüren Maven projesi |
| [TestTR for VS Code](projects/testtr-vscode/README.md) | TestTR senaryolarını düzenlemek, doğrulamak ve çalıştırmak için VS Code eklentisi |
| [TestTR Discovery](projects/testtr-discovery/README.md) | Otomatik DOM obje keşfi ve kullanıcı etkileşim kaydı için bağımsız Java/Playwright aracı |
